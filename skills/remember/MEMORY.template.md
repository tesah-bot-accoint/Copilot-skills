# Memory

Working memory for this project: facts, preferences, corrections and patterns Copilot has learned while working here. Copilot writes this file freely. It is the fluid half of the pair; `ONTOLOGY.md` is the fixed half and changes only with your approval.

`consolidate-memory` prunes entries that have faded and proposes the ones that keep proving useful as `ONTOLOGY.md` entries.

Entry format (one line each, newest at the bottom of its section):

    - [first: YYYY-MM-DD | last: YYYY-MM-DD | uses: N] The fact, in ontology terms. (source: where it came from)

Add `| pinned` after the use count for things you said must never be forgotten.
